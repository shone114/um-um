Maze rendering assets:

- `wall.png` — straight walls and the fallback texture for corners/junctions.
- `wall_end.png` — wall endpoints and decorative outer-frame corners.
- `tile1.png`, `tile2.png`, `tile3.png` — deterministic visual variants for open floor cells.

All assets are presentation-only. The logical board remains a 15×15 maze managed by the game server.
